# 文件格式转换：能力选择与核验

此文件定义工作流程，不代表本技能自带所有转换器。遵循用户指定的源文件、目标格式、范围、模板和平台权限；保持原件，另存新文件，避免覆盖。先检查文件能否读、类型与扩展名是否匹配、文件数量及页数/工作表、加密和损坏状态；信息已明确不重复询问。

## 根据任务选择
- Word / 可编辑文档 → PDF：优先平台实际可用的文档导出功能；检查页数、文字、表格、分页、图像与字体，页面显示是否核验需如实报告。
- PDF → Word：可提取文本与扫描件分流；按需使用 PDF 文本提取、文档生成或 OCR/视觉工具；重建为可编辑文档不保证原排版，必要时请用户确认文字优先还是版式优先，含表格时检查列对齐与数字。
- Word、PDF 或图片 → Excel：依 `document-to-excel.md` 转换、追踪、逐项核查数字；扫描件须依赖实际 OCR 能力。本包工具仅针对简单 DOCX 文本表格输出单元格明细，不等于复原原表。
- Excel / CSV ↔ 另一种表格格式：确认工作表、编码、分隔符、字段及目标文件；CSV 不保存多个工作表、格式、合并、图片或公式逻辑。多表转 CSV 须明确输出哪些表和命名，保留原始值并检查前导零、长数、日期、小数、符号、空值和行列数。不能仅凭扩展名或原表显示来推断数值原貌。
- Excel → PDF：确认要导出的工作表与打印范围，检查分页、表头、宽表、空白页及数字；不得声称未做的页面检查。
- 图片格式互转（如 PNG/JPEG）：依平台实际工具完成，确认尺寸及透明背景是否重要；JPEG 不支持透明背景且有损，不能擅自承诺无损或保留所有元数据。图片转 PDF 时检查顺序、方向与可读性。
- 其他格式：根据用户目标检查平台实际转换工具，能力不足时按 `skill-discovery.md` 发现并核查；无可用工具则报告限制，不能把改扩展名说成转换完成。

## 数字和交付核验
数字、编号、金额、表头和来源按 `document-to-excel.md` 逐项核对；不确定的字符标待核实，空值不当零。不因转换擅自修改金额、精度、币种或日期。输出前后检查源文件与目标文件，重新打开目标核对实际范围、页/表/行数量、重点数值和异常；对页面呈现和功能性未做的检查明确说明。只在实际完成、验证相应内容后才声明完整、可编辑、原样或无损。不得自动上传原始资料到额外服务。
